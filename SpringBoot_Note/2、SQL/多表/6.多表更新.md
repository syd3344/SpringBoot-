## 概述

> - 在 SQL 中，多表更新（也称为**多表联合更新**）允许你同时更新多个表的数据。
> - 不同的数据库管理系统（DBMS）有不同的语法来实现多表更新，通常你可以通过使用 `JOIN` 或 `WHERE` 子查询的方式实现。



## MySql中的多表更新 -- Join  on

### 概述

> - 在 `UPDATE` 语句中使用 `JOIN` 来同时更新多张表

```sql
UPDATE 表1
JOIN 表2 
ON 表1.关联字段 = 表2.关联字段
SET 表1.字段 = 新值, 表2.字段 = 新值
WHERE 条件;
```

### 示例

> - 假设有两张表：`users` 和 `orders`，`users` 表存储用户信息，`orders` 表存储订单信息。
> - 我们想要更新 `users` 表中的用户信息，并同时更新 `orders` 表中属于该用户的订单状态。

```mysql
UPDATE users u
JOIN orders o 
ON u.user_id = o.user_id
SET u.status = 'inactive', o.status = 'canceled'
WHERE u.last_login < '2023-01-01';
```
