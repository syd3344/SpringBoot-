## 插入顺序

> - **==首先插入主表==**（如用户表）
>   - 因为从表通常包含主表的外键（如用户 ID）
>   - 因此我们必须先插入主表以获得主表的主键（如 `id`）
>   - 然后再将该主键作为外键插入从表。
> - **==然后插入从表==（如角色表）**
>   - 在插入从表时，需要使用主表中生成的主键作为外键，确保数据的关联性。



## @Options(useGeneratedKeys = true, keyProperty = "id")

### 解释

> - **生成主键**：
>   - 在插入主表数据（如用户数据）时，数据库会根据 `AUTO_INCREMENT` 或其他机制为主表的主键字段（如 `id`）自动生成一个唯一的值。
> - **返回主键**：
>   - `@Options` 注解会自动将数据库生成的主键值返回，并赋值给插入操作时对应的 **==POJO 实体对象==** 的 `id` 字段

### 作用

> - **useGeneratedKeys = true**
>   - **==表示启用自动获取生成的主键==**
>     - 数据库中的某些字段（如 `AUTO_INCREMENT`）会自动生成主键。
>     - 启用此选项可以让 MyBatis 自动获取生成的主键。
> - **keyProperty = "id"**
>   - ==**表示将生成的主键值设置为实体对象（如  User  对象）的  id  属性中**==



## 流程

### 数据库表设计

> - **用户表 (users)**
>   - `id` (主键)
>   - `username` (用户名)
>   - `email` (电子邮件)
> - **角色表 (roles)**
>   - `id` (主键)
>   - `role_name` (角色名称)
>   - `user_id` (外键，关联用户表)

```mysql
CREATE TABLE users (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(50) NOT NULL,
    email VARCHAR(100) NOT NULL
);

CREATE TABLE roles (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    role_name VARCHAR(50) NOT NULL,
    user_id BIGINT,
    FOREIGN KEY (user_id) REFERENCES users(id)
);
```

### 定义实体类

```java
// User
@Data
public class User {
    private Long id; // 主键
    private String username; // 用户名
    private String email; // 电子邮件
}

// Role
@Data
public class Role {
    private Long id; // 主键
    private String roleName; // 角色名称
    private Long userId; // 外键，关联用户表
}
```



### 定义DTO类

```java
// UserRoleDTO
@Data
public class UserRoleDTO {
    private String username;
    private String email;
    private List<RoleDTO> roles; // 角色列表
}

// RoleDTO
@Data
public class RoleDTO {
    private String roleName;
}
```



### 创建Mapper接口

```java
// UserMapper
@Mapper
public interface UserMapper {
    @Insert("INSERT INTO users(username, email) VALUES(#{username}, #{email})")
    @Options(useGeneratedKeys = true, keyProperty = "id") // 自动生成 ID
    int insertUser(User user);
}

// RoleMapper
@Mapper
public interface RoleMapper {
    @Insert("INSERT INTO roles(role_name, user_id) VALUES(#{roleName}, #{userId})")
    int insertRole(Role role);
}
```



### 实现Service层

```java
@Service
public class UserService {

    @Autowired
    private UserMapper userMapper;

    @Autowired
    private RoleMapper roleMapper;

    @Transactional // 确保操作的原子性
    public void saveUserWithRoles(UserRoleDTO userRoleDTO) {
        // 1. 创建 User 对象
        User user = BeanUtil.toBean(userRoleDTO,User.class)

        // 2. 插入用户并获取生成的 ID
        userMapper.insertUser(user);
        Long userId = user.getId(); // 获取生成的用户 ID

        // 3. 遍历角色列表并插入角色表
        for (RoleDTO roleDTO : userRoleDTO.getRoles()) {
            Role role = BeanUtil.toBean(roleDTO,Role.class)
            role.setUserId(userId); // 设置外键
            roleMapper.insertRole(role);
        }
    }
}
```



### 创建Controller层

```java
@RestController
@RequestMapping("/users")
public class UserController {

    @Autowired
    private UserService userService;

    @PostMapping
    public ResponseEntity<String> createUser(@RequestBody UserRoleDTO userRoleDTO) {
        userService.saveUserWithRoles(userRoleDTO);
        return ResponseEntity.ok("用户和角色创建成功");
    }
}
```
