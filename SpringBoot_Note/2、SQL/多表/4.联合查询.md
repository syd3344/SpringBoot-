## 概述

> - 用于将==**多个 SELECT 语句的结果合并**==到一个结果集中。
> - 使用联合查询时，所有的 `SELECT` 语句必须具有**==相同数量的列==**，并且列的**==数据类型必须兼容==**
> - 联合查询只返回不同的记录（**==去重==**）
> - SQL 中的 `UNION` 和 `UNION ALL` 是实现联合查询的主要关键字。
>   - Union：
>     - 用于合并两个或多个select语句的结果集，会**==自动去除重复行==**
>   - Union All：
>     - 与union 类似，但**==不会去重==**，会保留所有行



## 使用场景

> - 用于将多个表或查询的结果合并为一个结果集
> - 针对不同条件或不同来源的数据进行汇总



## 基本语法

```mysql
SELECT column1, column2, ...
FROM table1
WHERE condition1

UNION

SELECT column1, column2, ...
FROM table2
WHERE condition2;
```



## 示例

### 需求及表结构

> - 假设我们有两个表：`employees` 和 `contractors`，分别存储正式员工和合同工的信息。

#### 表结构：`employees`

| id   | name    | position  |
| ---- | ------- | --------- |
| 1    | Alice   | Developer |
| 2    | Bob     | Designer  |
| 3    | Charlie | Manager   |

#### 表结构：`contractors`

| id   | name  | position      |
| ---- | ----- | ------------- |
| 1    | David | Developer     |
| 2    | Eve   | UX Researcher |
| 3    | Frank | Designer      |

#### 需求

> - 我们希望获取所有开发人员的姓名，不论他们是正式员工还是合同工。

### SQL

```mysql
SELECT name, position
FROM employees
WHERE position = 'Developer'

UNION

SELECT name, position
FROM part_time_employees
WHERE position = 'Developer'
```

### 结果

| name    | position  |
| ------- | --------- |
| Alice   | Developer |
| Bob     | Developer |
| Charlie | Developer |
| Eve     | Developer |



## 注意点

> - **列数必须相同**：所有参与联合查询的 `SELECT` 语句，返回的列数必须相同。
> - **数据类型必须兼容**：各个查询的相应列的数据类型需要兼容，例如不能在一个查询中返回整数，另一个查询返回字符串。
> - **列名采用第一个查询的列名**：结果集中列的名称会使用第一个 `SELECT` 语句的列名。
