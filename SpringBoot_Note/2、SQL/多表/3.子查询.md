**==本质：类似于递归，在结果集中查询==**

## 概述

> - 子查询（Subquery）是 SQL 中用于嵌套在另一条查询中的查询。
> - 一般用于解决复杂的查询需求，通常放在圆括号内，它可以出现在 SQL 语句的不同位置。
>   - 它可以出现在 `SELECT`、`FROM`、`WHERE`、`HAVING` 等子句中，通过执行子查询结果为外部查询提供数据

## 类型

> - 标量子查询
>   - 返回单个值
> - 行子查询
>   - 返回一行
> - 表子查询
>   - 返回一个表的结果集

## 使用场景

> - **在 WHERE 子句中使用**：过滤条件。
> - **在 SELECT 子句中使用**：作为选择的列之一。
> - **在 FROM 子句中使用**：作为虚拟表。
> - **在 HAVING 子句中使用**：用于聚合过滤条件。



### where 子句中使用 -- 作为条件

> - 使用子查询对结果集进行过滤
> - 查找某个比平均值更高的记录

```sql
SELECT emp_name, salary
FROM employees
WHERE salary > (SELECT AVG(salary) FROM employees)
```



### Select子句中使用 -- 作为计算结果

> - 作为一列返回

```sql
SELECT emp_name, 
       (SELECT department_name 
        FROM departments 
        WHERE departments.department_id = employees.department_id) AS department_name
FROM employees;
```



### 在From中使用 --  作为表

> - 子查询可以在 `FROM` 子句中作为一个临时表来使用，也称为派生表。

```sql
SELECT dept_name, avg_salary
FROM (SELECT department_id, AVG(salary) AS avg_salary 
      FROM employees 
      GROUP BY department_id) AS department_avg
JOIN departments 
ON department_avg.department_id = departments.department_id;
```



### 在In子句中使用 -- 作为集合

```mysql
SELECT name 
FROM employee 
WHERE department_id IN (SELECT id FROM department WHERE location = 'NYC');
```



### 在Having中使用

```mysql
SELECT salesperson, SUM(total_sales) AS total_sales
FROM sales
GROUP BY salesperson
HAVING SUM(total_sales) > (SELECT AVG(total_sales) FROM sales);
```
