## 常见聚合函数

###  **count()**

> - `COUNT()` 用于计算结果集中的行数，通常用来统计数据行的数量。

```sql
SELECT COUNT(*) FROM employees;
```

> - 这个查询会返回 `employees` 表中员工记录的总数。

### **sum()**

> - `SUM()` 用于对数值列进行求和。它适用于计算一列数值数据的总和，如总销售额或收入。

```sql
SELECT SUM(salary) FROM employees;
```

> - 这个查询会返回所有员工的薪资总和。

### **avg()**

> - `AVG()` 用于计算数值列的平均值。它适用于获取某个数值列的平均值，如平均薪资或平均价格。

```sql
SELECT AVG(salary) FROM employees;
```

> - 这个查询会返回员工薪资的平均值。

###  **max()**

> - `MAX()` 返回列中的最大值。它通常用于获取数据集中某个属性的最大值，如最高薪资或最高分数。

```sql
SELECT MAX(salary) FROM employees;
```

> - 这个查询会返回员工薪资中的最高值。

###  **min()**

`MIN()` 与 `MAX()` 类似，但返回的是列中的最小值。

```
sql复制代码SELECT MIN(salary) FROM employees;
```

> - 这个查询会返回员工薪资中的最低值。

### **group_concat()**

`GROUP_CONCAT()` 是一个 MySQL 中常见的函数，用于将某列的多个值连接成一个字符串。它在有分组操作时非常有用。

```
sql复制代码SELECT department, GROUP_CONCAT(name) 
FROM employees
GROUP BY department;
```

> - 这个查询会返回每个部门的员工姓名，并将他们连接成一个字符串。



##  聚合与 `group by` 结合

> - ==**聚合函数通常与  group by  子句一起使用，用于对某些字段进行分组，然后对每个分组应用聚合函数**==
> - 例如，统计每个部门的员工总数或每个城市的订单总额。

```sql
SELECT department, COUNT(*) 
FROM employees
GROUP BY department;
```

> - 这个查询会返回每个部门的员工数量
