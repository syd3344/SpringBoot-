> - 在插入数据时返回字段，可以根据具体的数据库和ORM框架的特性实现。常见的做法有：

###  **MyBatis（或 MyBatis-Plus）插入并返回字段**

> - 在使用 MyBatis 或 MyBatis-Plus 时，可以通过自增字段返回主键，也可以通过其他返回类型实现。

#### MyBatis 配置：

> - 使用 `useGeneratedKeys` 和 `keyProperty` 来返回主键：

```xml
<insert id="insertEmployee" useGeneratedKeys="true" keyProperty="id">
    INSERT INTO employees (name, age) VALUES (#{name}, #{age})
</insert>
```
#### 调用方式：
```java
Employee employee = new Employee();
employee.setName("John");
employee.setAge(30);
employeeMapper.insertEmployee(employee); // 此时 employee 对象的 id 字段会被自动填充
System.out.println("Inserted ID: " + employee.getId());
```

### 3. **MyBatis-Plus 插入并返回主键**

> - MyBatis-Plus 的 `ServiceImpl` 提供了一些便捷方法，可以直接使用 `insert` 方法来插入数据，并返回自增主键。

```java
Employee employee = new Employee();
employee.setName("John");
employee.setAge(30);
employeeService.save(employee); // 调用 MyBatis-Plus 提供的 save 方法
System.out.println("Inserted ID: " + employee.getId());
```

> - MyBatis-Plus 中的 `save()` 方法在执行后，会自动将自增主键填充到实体对象中。

### 4. **使用 SQL `RETURNING` 语句**
> - 在某些数据库中（如 PostgreSQL），可以通过 `RETURNING` 关键字在插入时直接返回指定的字段，如主键或其他字段。

```sql
INSERT INTO employees (name, age) VALUES ('John', 30) RETURNING id;
```
> - 这种方式需要数据库支持，执行后会返回插入的 `id`。
