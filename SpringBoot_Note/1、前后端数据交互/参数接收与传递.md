## Controller

### 键值对

> - 直接接

```java
@RequestMapping("/complex")
    public Result test(User user) {
        return Result.success(user);
    }
```



### 一个key多个value -- 数组

```java
//数组 一个key多个值
    @RequestMapping("/arrayParam")
    public Result arrayParam(String[] hobby) {
        return Result.success(hobby);
    }
```



### Json对象 -- @RequestBody

```java
@PostMapping("/create")
public String createUser(@RequestBody User user) {
    // 使用user对象进行处理
    return "User Created: " + user.getName();
}
```



###  可变参数  -- @PathVariable

```java
@RequestMapping("/variablePath/{id}/{name}")
    public String jsonTest(@PathVariable int id,@PathVariable String name) {
        log.info(String.valueOf(id)+","+name);
        return "success:"+id+","+name;
    }
```



### 日期 -- 设定日期格式

> -  LocalDateTime
>   - **==@DateTimeFormat==**

```java
@RequestMapping("/dateParam")
    public String timeParam(@DateTimeFormat(pattern = "yyyy年MM月dd日 HH:mm:ss")LocalDateTime updateTime) {
        log.info(String.valueOf(updateTime));
        return "success";
    }
```



### 接收绑定 -- @RequestParam

> - 将值绑定和参数绑定
> - **==age 参数是前端传递的==**

```java
@GetMapping("/users")
public List<User> getUsers(@RequestParam("age") int age, @RequestParam("name") String name) {
    // 使用age和name进行过滤
    return userService.findUsers(age, name);
}
```



### Dto层 捆绑  --  @JsonProperty

> - **对象嵌套的情况**：如果 JSON 中包含嵌套对象，你可以继续使用 `@JsonProperty` 来映射嵌套对象中的字段。

```json
{
  "user_name": "Tom",
  "pass_word": "123456"
}
```



```java
public class User {
    @JsonProperty("user_name")
    private String username;

    @JsonProperty("pass_word")
    private String password;

}
```

## Mapper

### 数据库字段与Vo字段不一致

#### 自定义映射 -- **==设置别名==**

```
<!-- 按 Id查询 -->
    <select id="selectById" resultType="com.zzyl.vo.NursingProjectPlanVo">
        select npn.*,np.name as project_name
        from nursing_project_plan npn
        join nursing_project np
        on npn.project_id = np.id
        where plan_id = #{id};
    </select>
```

##### Vo

```java
@Data
public class NursingProjectPlanVo extends BaseVo {
    /*执行周期*/
    private Integer executeCycle;
    /*执行频次*/
    private Integer executeFrequency;
    /*期望执行时间*/
    private String executeTime;
    /*计划Id*/
    private Integer planId;
    /*项目Id*/
    private Integer projectId;
    /*项目名称*/
    private String projectName;
}
```

##### nursing_project -- 数据库

```sql
create table nursing_project
(
    id                  bigint auto_increment comment '编号'
        primary key,
    name                varchar(100)                       null comment '名称',
    order_no            int                                null comment '排序号',
    unit                varchar(50)                        null comment '单位',
    price               decimal(10, 2)                     null comment '价格',
    image               varchar(255)                       null comment '图片',
    nursing_requirement varchar(255)                       null comment '护理要求',
    status              int      default 1                 not null comment '状态（0：禁用，1：启用）',
    create_by           varchar(50)                        null comment '创建人',
    update_by           varchar(50)                        null comment '更新人',
    remark              varchar(255)                       null comment '备注',
    create_time         datetime default CURRENT_TIMESTAMP not null comment '创建时间',
    update_time         datetime default CURRENT_TIMESTAMP null on update CURRENT_TIMESTAMP comment '更新时间',
    constraint name
        unique (name)
)
    comment '护理项目表' charset = utf8mb4;
```

##### nursing_project_plan -- 数据库

```sql
create table nursing_project_plan
(
    id                int auto_increment
        primary key,
    plan_id           int          not null comment '计划id',
    project_id        int          not null comment '项目id',
    execute_time      varchar(50)  not null comment '计划执行时间',
    execute_cycle     int          not null comment '执行周期 0 天 1 周 2月',
    execute_frequency int          not null comment '执行频次',
    create_time       datetime     not null comment '创建时间',
    update_time       datetime     null comment '更新时间',
    create_by         bigint       null comment '创建人id',
    update_by         bigint       null comment '更新人id',
    remark            varchar(255) null comment '备注'
)
    comment '护理计划和项目关联表' charset = utf8mb4;
```
