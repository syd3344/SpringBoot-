## 概述

> - `PageHelper` 是 MyBatis 的一个分页插件，用于简化分页操作。
> - 它通过拦截 SQL 语句来实现分页功能，开发者无需手动在 SQL 中编写 `LIMIT` 和 `OFFSET` 之类的分页语句。



## 机制解析

> - **PageHelper.startPage(pageNum, pageSize)  和  userMapper.selectAllUsers()  的配合使用是  PageHelper  实现分页的核心机制**
> - **PageHelper.startPage ( pageNum, pageSize )**
>   - `PageHelper.startPage()` 是分页助手静态方法，它会通过 `ThreadLocal` 保存分页信息，如当前页码、每页大小等。
>   - ==**方法本身不执行任何查询操作，它只是在  ThreadLocal  中保存分页信息，并通过拦截器机制，在接下来的查询执行时，自动在 SQL 中加入  LIMIT  和  OFFSET  分句。**==
>   - 在调用这个方法之后，**PageHelper 会为紧接着执行的 SQL 查询添加分页的限制（`LIMIT` 和 `OFFSET**`），确保查询结果只返回当前页的数据。
>   - 用于告诉 MyBatis 在接下来的查询操作中要进行分页，在 `startPage()` 调用之后，PageHelper 会拦截接下来的 SQL 查询，将分页参数（`LIMIT` 和 `OFFSET`）动态添加到 SQL 语句中。
>     - 假设mapper的语句是  Select * from user;
>     - 自动添加分页语句

## 使用流程

### 引入依赖

```xml
<dependency>
    <groupId>com.github.pagehelper</groupId>
    <artifactId>pagehelper</artifactId>
    <version>5.2.0</version>
</dependency>
```



### 配置PageHelper

> - 在 Spring Boot 中，你可以通过 `application.yml` 或 `application.properties` 配置 `PageHelper` 的一些参数，也可以通过 Java 配置类进行配置。

```yml
pagehelper:
  helperDialect: mysql   # 数据库方言，支持 MySQL、PostgreSQL 等
  reasonable: true       # 是否合理化页码
  supportMethodsArguments: true  # 支持在方法参数中传递分页参数
  params: count=countSql  # 设置count查询参数
```

### 在 Service 层使用PageHelper

> - 分页查询的核心步骤有两个：
>   - **启动分页：** 使用 `PageHelper.startPage()` 方法启动分页。
>   - **执行查询：** 执行查询方法，此时 `PageHelper` 会自动在 SQL 中添加分页的 `LIMIT` 语句。
>     - 返回结果自动封装为**==Page对象==** -- 本质是个List
>     - **==PageResponse==**

```java
@Service
public class NursingProjectService {

    @Autowired
    private NursingProjectMapper nursingProjectMapper;

    public PageResponse<NursingProjectVo> getNursingProjects(int pageNum, int pageSize, String name, Integer status) {
        
        // 启用分页
        PageHelper.startPage(pageNum, pageSize);
        
        // 执行查询
        // 返回分页后的结果，nursingProjects 自动封装为 Page 对象
         Page<NursingProjectVo> page = nursingProjectMapper.selectByPage(name, status)

        // 通过自定义的 PageResponse 返回分页数据和分页信息
        return PageResponse.of(page, NursingProjectVo.class);
    }
}

```

#### 解析

> - `nursingProjectMapper.selectByPage(name, status)` 返回的是  List< **==NursingProjectVo==** >  
>   - 通过 `Mapper` 层执行查询后，会将结果封装为 `NursingProjectVo` 列表返回给 Service 层，然后再返回给前端。
>   - 最后将 `Page` 对象转换成自定义的 `PageResponse` 对象，以便更好地进行前端数据展示。
>     - **封装分页结果**：
>       - 将 `Page` 对象中的数据（如记录列表、总记录数等）封装到 `PageResponse` 对象中，便于返回给调用者。
>     - **传递类型信息**：
>       - `NursingProjectVo.class` 作为类型参数，可能用于帮助 `PageResponse` 知道如何处理和返回数据，特别是在序列化或类型检查时。

### Page对象

> - `PageHelper` 分页查询的结果会自动封装为一个  ==**Page  对象，它继承自  ArrayList ，因此你可以像  List  一样使用它**==
> - `Page` 对象**==提供了分页相关的元数据，比如总记录数、总页数、当前页码等。==**

#### 常见方法：

> - `getTotal()`: 返回总记录数。
> - `getPages()`: 返回总页数。
> - `getPageNum()`: 返回当前页码。
> - `getPageSize()`: 返回每页记录数。
> - `getResult()`: 返回查询结果列表。



### 结果封装

> - 通常，分页查询返回的结果不仅包括查询的数据，还包括分页的元信息。
> - 你可以通过自定义响应对象来统一分页结果，比如使用 `PageResponse` 类。

```java
public class PageResponse<T> {
    private List<T> data;       // 查询结果
    private long total;         // 总记录数
    private int pageNum;        // 当前页码
    private int pageSize;       // 每页记录数
    private int totalPages;     // 总页数

    // 静态方法封装分页结果
    public static <T> PageResponse<T> of(Page<T> page, Class<T> clazz) {
        PageResponse<T> response = new PageResponse<>();
        response.setData(page.getResult());  // 获取分页结果
        response.setTotal(page.getTotal());  // 获取总记录数
        response.setPageNum(page.getPageNum());  // 当前页码
        response.setPageSize(page.getPageSize());  // 每页大小
        response.setTotalPages(page.getPages());  // 总页数
        return response;
    }
}
```



## 完整示例

### Controller

```java
@RestController
@RequestMapping("/users")
public class UserController {
    @Autowired
    private UserService userService;

    @GetMapping("/list")
    public PageInfo<User> getUserList(
            @RequestParam(defaultValue = "1") int pageNum, 
            @RequestParam(defaultValue = "10") int pageSize) {
        return userService.getUsersByPage(pageNum, pageSize);
    }
}

```

### Serveise

```java
@Service
public class UserService {
    @Autowired
    private UserMapper userMapper;

    public PageInfo<User> getUsersByPage(int pageNum, int pageSize) {
        // 开始分页
        PageHelper.startPage(pageNum, pageSize);
        
        // 执行查询
        List<User> users = userMapper.selectAllUsers();
        
        // 获取分页信息
        return new PageInfo<>(users);
    }
}
```

### 配置分页拦截器

> - 在启动类中直接配置也行,一样,但不推荐
> - **方法本身不执行任何查询操作，它只是在 `ThreadLocal` 中保存分页信息，并通过拦截器机制，在接下来的查询执行时，自动在 SQL 中加入 `LIMIT` 和 `OFFSET` 分句。**

```java
@Configuration
public class MybatisPlusConfig {

    @Bean
    public MybatisPlusInterceptor mybatisPlusInterceptor() {
        // 创建Mybatis-Plus分页拦截器
        MybatisPlusInterceptor interceptor = new MybatisPlusInterceptor();
        // 添加分页拦截器
        interceptor.addInnerInterceptor(new PaginationInnerInterceptor());
        return interceptor;
    }
}
```
