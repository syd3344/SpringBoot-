## 概述

> - **前端发送日期格式**：
>   - 前端在表单或 API 请求中发送的日期格式可能为  **==字符串==**，例如 `2024-10-13` 或带时间的 `2024-10-13T15:30:00`。
> - **后端接收日期参数**：
>   - 后端通常使用 Java 的  **==日期时间类型==**，如 `LocalDate`、`LocalDateTime`、`Date` 来接收日期数据。
> - **数据绑定和格式化**：
>   - 为了确保数据正确传递和格式化，后端可能需要指定日期格式或使用相应的 ==**转换器**==



## 参数接收

### **==自动转==**

> -  **接收 LocalDate 或 LocalDateTime 类型的日期**
>   - 可以直接在控制器方法中定义参数为 `LocalDate` 或 `LocalDateTime`
>   - **Spring Boot 自动将前端传递的日期字符串转换为相应的日期类型**
> - 

```java
@RestController
@RequestMapping("/api/reservations")
public class ReservationController {

    @PostMapping("/create")
    public String createReservation(
            @RequestParam("userId") Integer userId,
            @RequestParam("reservationDate") LocalDate reservationDate) {
        // 处理预订
        System.out.println("User ID: " + userId);
        System.out.println("Reservation Date: " + reservationDate);
        return "Reservation created";
    }

    @PostMapping("/createWithTime")
    public String createReservationWithTime(
            @RequestParam("userId") Integer userId,
            @RequestParam("reservationDateTime") LocalDateTime reservationDateTime) {
        // 处理预订
        System.out.println("User ID: " + userId);
        System.out.println("Reservation DateTime: " + reservationDateTime);
        return "Reservation with DateTime created";
    }
}
```



### @requestBody绑

> - 如果前端通过 JSON 发送数据，你可以使用 `@RequestBody` 来接收整个对象，并在对象中自动绑定日期字段。

```json
{
  "userId": 123,
  "reservationDate": "2024-10-13",
  "reservationDateTime": "2024-10-13T15:30:00"
}
```



```java 
@Data
public class ReservationDTO {
    private Integer userId;
    private LocalDate reservationDate;
    private LocalDateTime reservationDateTime;
}
```



```java
@RestController
@RequestMapping("/api/reservations")
public class ReservationController {

    @PostMapping("/createWithBody")
    public String createReservationWithBody(@RequestBody ReservationDTO reservation) {
        System.out.println("User ID: " + reservation.getUserId());
        System.out.println("Reservation Date: " + reservation.getReservationDate());
        System.out.println("Reservation DateTime: " + reservation.getReservationDateTime());
        return "Reservation created from JSON body";
    }
}
```



**@ DateTimeFormat**

> - Spring Boot 默认支持 `ISO-8601` 格式的日期时间（如 `2024-10-13` 和 `2024-10-13T15:30:00`）。
> - 如果需要 **==自定义日期格式==**，可以使用 `@DateTimeFormat` 注解
>   - **==@DateTimeFormat(pattern = "yyyy/MM/dd") LocalDate date)==**
>   - 前端请求时可以发送类似 `2024/10/13` 的格式，`@DateTimeFormat` 会将其转换为 `LocalDate`

```java
@RestController
@RequestMapping("/api/customFormat")
public class CustomDateFormatController {

    @GetMapping("/date")
    public String getCustomDate(
            @RequestParam("date")
            @DateTimeFormat(pattern = "yyyy/MM/dd") LocalDate date) {
        // 输出接收的日期
        System.out.println("Received Date: " + date);
        return "Received Date: " + date;
    }
}
```
