## 新日期

> - LocalDate
>   - 年月日
> - LocalTime
>   - 时分秒
> - LocalDateTime
>   - 本地日期和时间
> - ZoneDateTime
>   - 时区的日期和时间
> - Instant：表示自 Unix 纪元（1970-01-01 00:00:00 UTC）起的毫秒数，通常用于时间戳。

```java
LocalDate date = LocalDate.now();             // 获取当前日期

LocalTime time = LocalTime.now();             // 获取当前时间

LocalDateTime dateTime = LocalDateTime.now(); // 获取当前日期和时间

ZonedDateTime zonedDateTime = ZonedDateTime.now();  // 获取当前带时区的日期时间
```



## 旧日期格式化  -- SimpleDateFormat

> - 提供了灵活的方式将日期转换为字符串（格式化），或从字符串解析为日期。
>   - `yyyy`：四位数的年（如 2024）
>   - `MM`：两位数的月（01-12）
>   - `dd`：两位数的日（01-31）
>   - `HH`：24小时制的小时（00-23）
>   - `mm`：分钟（00-59）
>   - `ss`：秒（00-59）

```java
// 格式对象
SimpleDateFormat sdf = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss");

// 日期对象
Date date = new Date();

// 格式化日期为字符串
String formattedDate = sdf.format(date);  
System.out.println(formattedDate);

// 从字符串解析为日期
Date parsedDate = sdf.parse("2024-10-13 15:00:00");  
```

## 新日期格式化 -- DateTimeFormatter

> - 线程安全

```java

// 格式对象
DateTimeFormatter formatter = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");

// 日期对象
LocalDateTime now = LocalDateTime.now();

// 格式化
String formattedDateTime = now.format(formatter);
System.out.println(formattedDateTime);

// 字符串解析为日期对象
LocalDateTime parsedDateTime = LocalDateTime.parse("2024-10-13 15:00:00", formatter);  
System.out.println(parsedDateTime);
```

## 时区

> - 处理时区时可以使用 `ZonedDateTime` 或 `OffsetDateTime`。
> - 如果需要处理全球用户的时间问题，这两个类非常有用。

### ZoneId.of ( "时区" )

```java
ZonedDateTime zonedDateTime = ZonedDateTime.now();
System.out.println(zonedDateTime);

ZonedDateTime utcTime = ZonedDateTime.now(ZoneId.of("UTC"));
System.out.println(utcTime);
```



## 日期加减

> - 通过 `plus()` 和 `minus()` 方法对日期和时间进行加减操作
> - 这些方法可以链式调用，可以在一次操作中对不同单位的时间进行加减
> - plus( )
>   - `plusYears(long yearsToAdd)`：加上指定的年数。
>   - `plusMonths(long monthsToAdd)`：加上指定的月数。
>   - `plusWeeks(long weeksToAdd)`：加上指定的周数。
>   - `plusDays(long daysToAdd)`：加上指定的天数。
>   - `plusHours(long hoursToAdd)`：加上指定的小时数。
>   - `plusMinutes(long minutesToAdd)`：加上指定的分钟数。
>   - `plusSeconds(long secondsToAdd)`：加上指定的秒数。
> - minus( )
>   - `minusYears(long yearsToSubtract)`：减去指定的年数。
>   - `minusMonths(long monthsToSubtract)`：减去指定的月数。
>   - `minusWeeks(long weeksToSubtract)`：减去指定的周数。
>   - `minusDays(long daysToSubtract)`：减去指定的天数。
>   - `minusHours(long hoursToSubtract)`：减去指定的小时数。
>   - `minusMinutes(long minutesToSubtract)`：减去指定的分钟数。
>   - `minusSeconds(long secondsToSubtract)`：减去指定的秒数。

```java
LocalDate today = LocalDate.now();

LocalDate nextWeek = today.plusWeeks(1);  // 加一周

LocalDate lastMonth = today.minusMonths(1);  // 减一个月
```



## 日期比较

> - 可以使用 `isBefore()`、`isAfter()` 和 `isEqual()` 方法进行日期比较
> - `Period` 
>   - 日期之间的差异



```java
public class PeriodExample {
    public static void main(String[] args) {
        LocalDate start = LocalDate.of(2020, 1, 1);
        LocalDate end = LocalDate.of(2024, 10, 13);

        Period period = Period.between(start, end);
        System.out.println(period.getYears());   // 4 年
        System.out.println(period.getMonths());  // 9 个月
        System.out.println(period.getDays());    // 12 天
    }
}
```

}

## 互相转换

> - `LocalDate`、`LocalDateTime`、`Instant` 之间进行转换
>   - 低精度  向  高精度   转

```java
// LocalDate 转 LocalDateTime
LocalDate localDate = LocalDate.now();
LocalDateTime localDateTime = localDate.atStartOfDay();

// LocalDateTime 转 Instant
Instant instant = localDateTime.toInstant(ZoneOffset.UTC);
```
